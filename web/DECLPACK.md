# web/public/declpack.bin contract (schemaVersion: 1)

Generated by: `leanatlas declpack --extract extract.jsonl --structure
structure.jsonl --data web/public/data.json --out web/public/declpack.bin`
(defaults shown; `--mathlib-path` or `LEANATLAS_MATHLIB_PATH` required, same
as `layout`). Only modules present as nodes in data.json get blocks.

## File layout

```text
[8 bytes LE uint64: byte length of the header JSON]
[header JSON, UTF-8, compact]
[module blocks concatenated, sorted by module name]
```

Header (offsets relative to the END of the header):

```jsonc
{
  "schemaVersion": 1,
  "meta": {
    "version": "mathlib git describe",
    "generatedAt": "ISO8601",
    "scope": "mathlib",
    "stats": { "modules": 0, "decls": 0, "edges": 0,
               "kindsInferred": 0, "duplicateNames": 0 }
  },
  "modules": { "Mathlib.X": { "o": 0, "l": 1234 } }
}
```

## Module block

```jsonc
{
  "schemaVersion": 1,
  "module": "Mathlib.X",
  "decls": [ // array index = node id, extract-file first-appearance order
    { "name": "Mathlib.X.f", "k": "theorem", "x": 0.0, "y": 0.0, "s": 1.5 }
  ],
  "e": [[1, 0]] // [srcIdx, dstIdx] = src DEPENDS ON dst (foundational on the right of the pair)
}
```

- `k`: joined from structure.jsonl parsed declarations by (module, name);
  inferred from record shape otherwise (instantiates -> instance,
  constructors -> inductive, extends -> class, else def).
- `name`: the declaration's Lean full name WITHOUT module prefix (e.g.
  `le_iff_eq_or_lt` in `Mathlib.Order.Basic`) — names are unique within a
  block; deep-link `#mod=X&node=<name>` pins use this unprefixed form.
- `x`/`y` are FINAL sigma coordinates (unlike data.json's band-value y that
  the client negates) — longest-path depth on the intra-dep DAG left =
  foundations, deterministic zigzag within columns, cycle members share one
  overflow column.
- `s`: node size from total intra-module degree, clamped to [1.5, 4.5].
- Edges: intra-module dependencies only (cross-module relations live at the
  module layer); self-loops and duplicates dropped. NOTE the direction
  convention is the OPPOSITE of data.json `edges` ([dep, importer]): here the
  pair points from the dependent at its foundation, matching
  structureEdges.

## Semantics

- Same inputs -> byte-identical output (generatedAt injected by the caller).
- typeSignature and source text are intentionally omitted (dominant payload;
  a future schemaVersion may add truncated signatures).
- The web client (`web/src/graph/declPack.ts`) reads the 8-byte prefix, then
  the header, then one ranged GET per drill; servers that ignore Range
  (vite dev) answer 200 and the client buffers the file once.
